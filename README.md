# 🎲 Dicee Game

This is a simple browser-based dice game built with HTML, CSS, and JavaScript. The project simulates a dice roll for two players and determines the winner based on random values.

## 📚 About

This project was developed as part of a web development course I’m currently taking, as well as a university programming assignment. It demonstrates basic DOM manipulation, event handling, and random number generation in JavaScript.

## 🚀 How It Works

- Press the **"Roll the Dice"** button or press the **spacebar** to start the game.
- Two dice are rolled automatically.
- The game displays which player wins or if it's a draw.

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
